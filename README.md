## Lancer le projet en local

Il suffit d'ouvrir le fichier `index.html` dans un navigateur.

Vous pouvez aussi utiliser l'extension VS Code **Live Server** pour voir les modifications en direct.

## Publication avec GitHub Pages

Apres avoir envoye les fichiers sur GitHub :

1. Aller dans les parametres du depot
2. Ouvrir l'onglet **Pages**
3. Choisir la branche `main`
4. Choisir le dossier `/root`
5. Enregistrer

Le site sera ensuite disponible a une adresse du type :

```text
https://TALEBWISSAME.github.io/Portfolio/
```
