# Portfolio développé — Taleb Wissame

Refonte React du portfolio, orientée développement logiciel et recherche d’alternance 2026–2027.

## Développement

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm run preview
```

## Déploiement GitHub Pages

1. Adapter `base` dans `vite.config.js` si le nom du dépôt change.
2. Exécuter `npm run deploy`.
3. Dans GitHub, choisir la branche `gh-pages` comme source Pages.

Les visuels conceptuels des projets peuvent être remplacés ultérieurement par de vraies captures d’écran.
